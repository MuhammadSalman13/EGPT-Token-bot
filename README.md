# EGPT Token Bot

EGPT Token Bot is a modern Telegram bot powered by GPT AI, designed to generate intelligent responses and assist users in Arabic and English conversations. Built with Python and optimized for cloud deployment (Railway-ready).

## Setup

1. Clone the repository
2. Set environment variable `BOT_TOKEN` with your Telegram Bot API key
3. Run `python egpt_full_bot_ready.py`

## Requirements

- Python 3.9+
- python-telegram-bot
- requests
